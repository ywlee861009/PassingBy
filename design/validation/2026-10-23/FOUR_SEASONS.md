# 사계절·자동 날씨 추가 검증

2026-10-23 · `4e0e0fc` 이후 제품 결정 반영. [제품 명세 7.4](../../../PASSING_BY_SPEC.md)와 함께 읽는다. 기본/가을 구현 시점의 [기존 기록](VALIDATION.md)은 당시 결과로 보존했다.

## 현재 동작

- 일반 설정: **봄/여름/가을/겨울**, **자동/낮/밤**. 날씨 선택은 제거했다. 자동 시간대에는 기존 새벽·노을 전환이 포함된다.
- 봄은 새잎·일부 꽃빛, 여름은 기존 녹음, 가을은 단풍, 겨울은 낙엽수 잔가지와 마른 식생으로 표현한다. 상록수·건물·랜드마크의 재질은 유지한다.
- 날씨는 선택한 계절·코스·세션 시드로 정한다. 봄은 간간이 비, 여름은 비/소나기 비중을 높이고, 가을은 맑음 위주다. 겨울에는 적설 가능한 코스에서만 눈이 온다. 따뜻한 코스의 겨울에는 비/맑음으로 변주한다.
- 겨울 기본 설경과 날씨 적설은 별도로 합성한다. 눈이 가능한 코스도 겨울 내내 강설하지 않는다. 겨울에서 다른 계절로 바꾸면 자동 날씨의 이전 강설·적설·유리 눈을 정리한다.
- 저장값 `default`, 누락/알 수 없는 계절은 여름으로 복원한다. 이전 새벽/노을 고정값은 낮/밤으로 복원한다. 예전 수동 날씨 저장값은 무시한다. 개발 패널·debug 실행 옵션의 날씨 고정은 임시 검증용이다.

## 검증 결과

- JVM **17개 통과**: 환경음 3, 결제 6, 계절 5, 계절별 날씨 3. 모든 계절·코스 특성에서 자동 강설 조건, 출력 범위, 비/눈 배타성, 동일 시드·시각의 재현, 부드러운 변화, 여름/가을의 강수 빈도 차이를 확인했다.
- Android 15/API 35 arm64 에뮬레이터 계측 **7개 통과**. 기존 오디오/캐시 시험 외에 사계절 저장과 이전 설정 이동, 이전 수동 눈 설정이 자동 날씨를 덮지 않음, 눈 없는 겨울 설경·따뜻한 코스의 무적설·계절 변경 시 눈 정리를 확인했다.
- 8개 코스×사계절, 한국/일본 낮·밤/맑음·비·눈/세로·가로, 8개 코스 겨울 DIRECT/BAKED/TILES를 합쳐 **144장**의 렌더 캡처를 생성했다. 비/눈 고정 캡처는 개발 강제 입력을 포함하므로 여름 자동 강설이 있다는 뜻은 아니다.
- BAKED에서 100회 사계절 전환 전후 비트맵 사용량이 동일했다. 겨울 잔가지 마스크는 초기화 때 한 번 만들고 재사용한다. 빠른 계절 전환 중 오래된 비동기 TILES 결과가 최신 계절을 덮지 않는지 확인했다.
- 실제 한국어·영어 설정 UI에서 사계절과 자동/낮/밤만 표시되고, 수동 날씨·새벽·노을 선택이 없음을 접근성 트리와 캡처로 확인했다.
- 디버그 APK, 테스트 APK, R8/리소스 축소 release APK 빌드 성공. debug/release Lint 오류 0개. 양국어 출시 노트 갱신(한국어 198자, 영어 444자).

[8개 코스 사계절 비교](four-seasons-courses.webp) · [한국어 설정](four-seasons-settings-ko.webp) · [영어 설정](four-seasons-settings-en.webp)

비교판은 고정 낮/맑음·첫 구간 거리 45%의 같은 위치를 사용하고, 차이가 보이도록 창 아래쪽을 잘라 축소 배치했다. 원본 전체 화면 144장은 로컬 `app/build/four-seasons-final/`에 있다. [소프트웨어 Canvas CPU 참고 측정](four-seasons-render-cpu.csv)은 40프레임 캐시 워밍업, 계절별 20프레임 추가 워밍업 후 100프레임 평균이며 실기기 GPU 프레임·배터리 수치가 아니다.

## 재실행

```sh
rtk proxy ./gradlew :app:assembleDebug :app:testDebugUnitTest :app:lintDebug :app:assembleDebugAndroidTest
rtk proxy ./gradlew :app:connectedDebugAndroidTest
rtk proxy ./gradlew :app:assembleRelease :app:lintRelease -x :app:uploadCrashlyticsMappingFileRelease
```

검증용 앱/테스트 APK 설치 후 `additionalTestOutputDir`를 지정한 계측 실행으로 캡처를 보존할 수 있다(기존 검증 기록의 명령 참고). 실기기 장시간 발열·배터리와 Play 라이선스 계정 실결제는 기존 미검증 항목으로 남아 있다.
