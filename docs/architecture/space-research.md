# 우주선 코스와 시각 연출

갱신일: 2026-10-28. 현재 우주 여행은 **명왕성으로 가는 여행**과 **블랙홀로 가는 여행** 코스를 제공한다. 블랙홀 코스는 지구 → 달 → 토성 → 해왕성 → 가상의 블랙홀 순서로 진행하며, 마지막에는 검은 중심과 빛나는 강착 원반을 멀리서 관측한다.

지구 → 달 → 목성 → 토성 → 명왕성.

중간 경유지는 달·목성·토성 3곳이며 종점은 명왕성이다. 안내는 `다음 정착지`, `… 곁에 머무는 중…`처럼 여행 문구를 사용한다.
실제 이동은 기존 근접 통과 방식이며, 타이머가 멈추거나 착륙하는 동작을 추가하지 않는다.

명왕성에 도달하는 시각이 집중 세션의 종료 시각이며, 명왕성 너머의 별도 구간을 만들지 않는다.
실제 항법 계획·행성 정렬·중력 보조 궤적을 계산하지 않으며 거리·크기·시간은 집중 세션에 맞춘다.

천체에 대한 기존 참고 자료:
- [NASA · Solar system planets](https://science.nasa.gov/solar-system/planets/)
- [NASA · Pluto](https://science.nasa.gov/dwarf-planets/pluto/)

기존 11개 코스는 선택 목록에서 제거하고 ID를 단일 코스의 별칭으로 유지한다.
저장된 우주선 여행은 같은 집중 시계와 방향으로 새 코스에서 복원한다. 미처리 완료 알림도 새 코스로 해석한다.
현재 코스의 저장 ID `space_solar_escape`는 호환성을 위해 유지하지만 표시 이름은 명왕성 여행이다.
`SpaceCourse`는 전달된 `bodies`만 정착지로 사용하며 마지막 천체를 종점으로 삼는다.
다음 코스는 고유 ID·이름·천체 목록·설명을 가진 별도 항목으로 추가한다. 현재 코스의 별칭으로 합치지 않는다.
현재의 지상 발사 연출은 지구 출발을 전제로 하며, 다른 천체에서 출발하는 코스는 발사 연출도 별도로 정의해야 한다.
외계행성 등 기존 그림 구현·보관된 관측 자료는 남아 있지만 현재 코스에는 포함하지 않는다.

## Canvas 풍경과 행성

기차 풍경처럼 Android Canvas의 경로·도형·그라디언트를 겹쳐 원본 일러스트를 그린다.
사진·다운로드 지도·미리 생성한 WebP는 사용하지 않으며 해당 파일과 생성 스크립트도 제거했다.
`EarthContours`의 수작업 경위도 윤곽을 직교 구면 투영해 대륙을 그리고, `PlanetPainter`에서
지형·구름·행성별 특징을 추가한다. 경계에서 뒷면을 잘라 대륙이 구면의 가장자리를 따라 휘도록 한다.

- 지구: 유라시아·아프리카·아메리카 등의 해안선, 지중해·카스피해, 사하라·아라비아,
  산맥·극지 얼음·끊어진 구름대와 나선형 기상계를 겹친다. 구름 배치와 조명은 연출이다.
- 목성: 위도에 따라 휘는 띠, 가는 난류 경계, 남반구의 대적점과 작은 소용돌이,
  극 방향 편평도를 그린다. 대적점의 현재 관측 크기·색·위치를 실시간으로 재현하지 않는다.
- 달·수성: 명암이 있는 크레이터·방사형 분출 흔적. 달의 어두운 바다 분포를 별도로 그린다.
- 금성: 지표를 노출하지 않고 두꺼운 구름의 곡선 무늬를 그린다.
- 화성: 적갈색 토양·어두운 영역·극관, 타르시스 화산과 매리너 계곡을 요약한다.
- 토성: 은은한 띠·극지 소용돌이와 북극 육각형, 카시니 간극을 가진 고리를 그린다.
- 천왕성: 옅은 청록색 구름층과 옆으로 기운 고리. 해왕성: 차분한 청색 띠와 가는 흰 구름,
  일시적인 폭풍의 해석도. 명왕성: 서로 다른 두 엽의 하트 지형과 밝은 평원 세포 무늬.
- 외계행성: 관측으로 확정하지 못한 지표는 코스 설명처럼 해석도임을 유지한다.

큰 행성은 최초 사용 때 Canvas로 1024px 메모리 비트맵에 그려 동시 최대 2개(약 8MiB)를 캐시한다.
작은 배경 천체는 별도의 192px 캐시로 최대 3개(약 432KiB)를 사용하며 전체 캐시는 기존 12MiB 한도 안에 든다.
프레임마다 수백 개의 지형 경로를 다시 계산하지 않으며, 화면 종료 시 캐시를 해제한다.
지상은 사진 대신 바다·산 능선·해안·습지·들판·수목을 Canvas 레이어로 그려 아래로 이동시킨다.

출발은 해안 지상 → 수직 상승·구름 통과 → 푸른 대기권 가장자리 → 궤도 회전 → 우주 항해다.
일반 세션에서는 3초 동안 상승한 뒤 1초 동안 항해 방향으로 회전하고, 12초에 달을 근접 통과한다.
짧은 테스트 세션은 이 시각을 비례해서 줄인다. 나머지 집중 시간은 목성·토성·명왕성으로 가는 세 구간에 배분한다.
각 행성의 접근·이탈은 최대 8초로 압축하고 그 사이를 순항해 행성이 오랫동안 창에 멈춰 있지 않게 한다.
별은 세션의 경과 초에 따라 일정한 속도로 흐르며 짧은 궤적과 깊이별 시차로 속도감을 표현한다.
세션 진행률에만 비례하던 별 이동을 제거해 25·50·90분에서도 같은 순항 속도감을 유지한다.

달 이후 명왕성까지 순항 구간에는 두 시차 레이어의 작은 천체가 46초 주기로 창을 가로지른다.
화성·위성·천왕성·해왕성의 기존 Canvas 그림을 작은 크기로 재사용하며 별도의 정착지 표시는 만들지 않는다.
큰 행성 근처에서는 작은 천체를 부드럽게 숨긴다. 별똥별은 약 6.5초마다 1.4초 동안 짧은 꼬리와 함께 스친다.
모든 위치·등장 시각은 세션 시계로 계산하고 프레임마다 새 천체·파티클을 생성하지 않는다.

남은 시간·방문 기록·왕복·위치 탐색·기동음은 같은 비균등 시간표를 사용한다.
진행 UI는 기차·우주 등 모든 모드에서 같은 배치를 사용한다. 각 목적지 이름은 해당 점 바로 아래에 놓는다.
점은 같은 간격으로 배치하고 현재 위치는 실제 도착 시간표의 구간 진행률을 보간한다.
따라서 12초에 지나는 달도 지구와 겹치지 않으며 실제 도착 시각과 남은 시간은 바뀌지 않는다.
이름은 각 점의 전용 너비 안에서 최대 두 줄까지 표시하며, 긴 문구도 옆 목적지와 겹치지 않는다.
위치 탐색은 가속된 카메라 경로의 역함수를 사용한다. 일시정지·탐색·재시작에도 같은
세션 진행률에서 같은 장면을 표시한다. 별 배경·조명·각지름·창틀은 연출이며 모든 풍경은 직접 그린 그림이다.

## 우주선 사운드

`SpaceAudio`가 `VoyageAudio`를 구현하며 우주선 모듈이 음색과 상태를 소유한다. 연속 PCM 스트림으로
이륙 엔진의 저음·중음 배음·기체 통과 공기음, 궤도 이후 공조/기계음, 근접 통과 시 자세 제어 추진기음을 합성한다.
외부 진공에서 소리가 전달된다는 표현이 아니라 선내에서 들리는 연출이다. 휴대폰에서도 들리도록
376/392/588Hz 등의 성분을 포함하며, 55Hz 단일 저음 위주였던 공통 루프는 우주선에서 사용하지 않는다.
기차·배·비행기 사운드는 기존 구현을 유지한다. 일시정지 때 엔진과 기동음은 줄고 조용한 선내음만 남는다.
기존 소리 켜짐/크기 설정을 따르며 화면이 가려지거나 꺼지면 정지하고, 화면 종료 시 AudioTrack을 해제한다.

## 드문 UFO 조우 (구현 완료, 2026-10-28)

UFO는 정착지나 수집 항목을 추가하지 않는 12초짜리 창밖 이벤트다. 은색 접시형 기체·청록색 돔과
점등된 창을 Canvas로 그리며, 화면 위쪽을 살짝 기울고 떠오르내리면서 가로지른다.
별도의 조작·팝업·점멸·경고음은 없다. 등장·퇴장은 각각 2초 동안 부드럽게 바뀐다.

- 25분 세션은 25% 확률로 최대 1회다. 50분은 2개의 기회, 90분은 3개의 기회를 각각 25% 확률로 선택한다.
- 한 번도 나타나지 않는 여행도 있으며, 연속으로 선택되어도 최소 15분 간격을 둔다.
- 각 기회 구간의 가운데 40% 안에 배치하고, 시작 3분·종료 전 1분과 모든 행성 조우 전후 24초를 피한다.
  10분보다 짧은 세션에서는 나타나지 않는다. 안전한 구간이 없으면 해당 기회를 생략한다.
- 저장된 세션 시드와 코스 ID로 등장 시각·방향·높이를 계산한다. `VoyageScene.eventSeed`는
  출발·설정·저장 복원 때 실제 세션 시드와 동기화한다. 프레임별 확률 판정이나 별도 재생 플래그는 없다.
- 화면과 음향은 같은 `SpaceUfo` 시간표와 페이드 곡선을 공유한다. 일시정지 시 그림이 멈추고 전용 음향은 줄어든다.
  음소거·앱 비활성화 시 기존 AudioTrack이 정지하며, 복원·탐색 시 현재 장면의 음색으로 이어진다.

음향 참고 자료는 [WHYY Fresh Air의 Robert Moog 인터뷰](https://freshairarchive.org/segments/synthesizer-inventor-robert-moog)다.
제작자가 직접 설명한 주기적 피치 변조, 테레민의 음높이 이동과 비브라토를 참고했다.
이를 바탕으로 약 640Hz의 중심음에 느린 피치 변화·4.8Hz 비브라토·3.1Hz 진폭 변화를 섞은 독자 합성음을 만들었다.
이는 레트로 SF 연출이며 특정 영화·음악·공개 음원 파일을 복제하거나 앱에 포함하지 않는다.
발진기 위상은 PCM 블록 사이에 유지하고 음량을 부드럽게 보간해 클릭을 방지한다.
기존 선내음 스트림 안에서 합성하므로 추가 MediaPlayer·다운로드·백그라운드 재생을 만들지 않는다.

검증은 25·50·90분 왕복의 등장 빈도·행성 충돌 회피·저장 복원·일시정지 일관성,
PCM 음량·페이드·클리핑과 실제 Android AudioTrack 재생, 세로·가로 Canvas 렌더링을 포함한다.
청취용 합성 미리보기는 단위 테스트가 `experience/spaceship/build/reports/space-ufo-preview.wav`에 만든다.

## 중간 이벤트 설계 (제안, 아직 구현하지 않음)

이하 소행성·혜성·탐사선의 확장 연출은 제안이며, 위의 드문 UFO 조우와 기존 배경 천체·빛줄기는 구현되어 있다.

목표는 오래 켜 둔 창밖에 구간별 변화를 주는 것이다. 집중 타이머를 계속 사용할 수 있도록
이벤트는 자동으로 지나가며 조작·보상 수령·팝업·푸시 알림을 요구하지 않는다.
기존 작은 천체와 6.5초 주기 빛줄기는 배경층으로 취급한다. 별똥별처럼 보이는 궤적은 사실적 관측이 아닌 여행 연출이다.
새 이벤트는 배경의 반복 주기를 늘리는 대신 15~35초 동안 알아볼 수 있는 장면을 만든다.

| 구간 | 주요 장면 | 화면과 소리 | 길이 / 우선순위 |
| --- | --- | --- | --- |
| 달 → 목성 | 소행성 무리 통과 | 앞뒤 크기가 다른 암석이 2~3개 시차 층으로 흐른다. 선내 저음을 조금 변화시킨다. | 25~35초 / 1차 |
| 목성 → 토성 | 긴 꼬리의 혜성 | 밝은 핵과 넓고 옅은 꼬리가 창을 천천히 가로지른다. 먼저 작게 나타나고 서서히 사라진다. | 18~25초 / 1차 |
| 토성 → 명왕성 | 탐사선과 먼 햇빛 | 작은 탐사선 실루엣과 태양전지판 반사가 지나간다. 수신음은 기존 음량 안에서 짧게 선택적으로 사용한다. | 15~20초 / 1차 |
| 각 순항 구간 | 먼 별무리·우주 먼지 | 저대비 별무리와 입자층으로 밀도·색감을 천천히 바꾼다. 큰 이벤트 사이의 정적인 화면을 완화한다. | 20~30초 / 2차 |
| 명왕성 접근 | 도착 전환 | 명왕성이 커지며 주변 이벤트를 정리하고, 완료 시 기존 도착 카드로 이어진다. | 기존 접근 구간 / 1차 |

이것은 코스별로 연출하는 상상 속 항해다. 소행성·혜성·탐사선의 실제 위치나 조우 확률을 주장하지 않는다.
빛줄기를 보았다는 이유로 목적지를 추가하거나 방문 수첩에 해당 천체를 방문한 것으로 기록하지 않는다.

### 등장 간격과 중복 제어

- 발사·달 통과 직후의 첫 30초는 기존 연출에 맡긴다.
- 큰 이벤트 사이에는 기본 90~150초의 간격을 둔다. 25분 세션은 약 8~10회의 장면 변화를 목표로 한다.
  50·90분 세션에서는 같은 수의 이벤트를 느리게 늘이지 않고 초 단위 간격을 유지하며 변형을 섞는다.
- 행성 접근·이탈 전후 12초와 마지막 도착 구간에는 이벤트를 겹치지 않는다. 자리가 없는 짧은 세션은 이벤트 수를 줄인다.
- 한 번에 큰 이벤트는 하나만 표시한다. 큰 장면이 있을 때는 기존 작은 천체·짧은 궤적의 밀도를 낮춘다.
- 같은 주요 이벤트는 연속 선택하지 않는다. 이동 방향·깊이·꼬리 방향·입자 밀도를 바꿔 재등장 차이를 만든다.
- 길이 15~35초 안에 등장·중심 장면·이탈을 포함한다. 등장·퇴장은 2~4초 동안 부드럽게 바꾼다.
- 화면 흔들림·급격한 섬광은 사용하지 않는다. 타이머·목적지·조작 버튼 영역은 읽을 수 있게 유지한다.

### 다음 코스를 위한 데이터와 구현 경계

`SpaceCourse`에 추후 `events: List<SpaceEventSpec>`와 순항 구간별 환경 테마를 추가한다.
이벤트는 전역 시간의 40%처럼 현재 코스에 묶지 않고 `fromBody`·`toBody`와 구간 내 비율로 지정한다.
예를 들어 달→목성의 소행성 장면은 그 구간이 있는 코스에서만 기본 후보가 된다.

`SpaceEventSpec` 제안 필드는 `id`, `kind`, `fromBody`, `toBody`, `preferredFraction`,
`durationSeconds`, `intensity`, `variantPool`이다. 행성 통과와 도착의 우선순위는 이벤트보다 높다.
경유지 추가·삭제 시에는 없는 구간의 이벤트를 제외하고 정상 구간에만 후보를 배치한다.

`SpaceEventTimeline`은 코스 설정 시 실제 시간표·세션 길이·세션 시드로 이벤트 목록을 한 번 만든다.
현재 구현의 `SpaceFlightPath`·`SpaceScenery`와 같은 세션 시계로 `sample(elapsedSeconds)`를 계산한다.
세션 시드는 저장된 `Active.weatherSeed`를 재사용하되 우주 이벤트용 난수 스트림을 별도로 파생한다.
프레임마다 난수를 생성하거나 이미 지났다는 플래그를 누적하지 않아도 같은 시각에 같은 장면이 나온다.

- 일시정지: 이벤트도 같은 위치에서 멈춘다.
- 탐색·복원: 해당 시각의 장면을 즉시 복구하며 건너뛴 이벤트를 몰아서 재생하지 않는다.
- 왕복: 실제 왕복 시간표와 방향에 맞춰 구간을 뒤집고 출발·도착 보호 구간을 다시 계산한다.
- 소리: 기존 `SpaceAudio` 스트림과 음량·음소거 설정을 따른다. 복원·탐색 때 수신음을 반복 발화하지 않는다.
- 성능: Canvas 도형·작은 캐시를 재사용하고 파티클 수를 제한한다. 설정·샘플링은 순수 데이터로 테스트한다.

1차 구현은 소행성 무리·혜성·탐사선과 공통 타임라인까지다. 이후 코스마다 배경 테마와 이벤트 후보만 추가한다.
검증 기준은 25·50·90분의 등장 공백, 행성 장면과의 충돌, 왕복·일시정지·탐색·재실행의 일관성,
한국어·영어 UI 가독성, 기존 비트맵 예산과 30fps 절전 모드 유지다.

### 블랙홀 렌즈 연출

블랙홀은 Canvas에서 직접 그린다. 뒤쪽 강착 원반의 위쪽 아치와 아래쪽 보조상을 먼저 그리고, 검은 중심과 얇은 광자 고리를 겹친 다음 앞쪽 원반을 그린다. 원반의 좌우 밝기 차이와 천천히 이동하는 밝은 결로 깊이와 회전을 표현한다. 일반상대론 광선 추적 대신 사용한 예술적 근사이며 배경 별의 위치를 왜곡하지는 않는다.
