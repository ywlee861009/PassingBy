# 우주선 코스와 시각 연출

갱신일: 2026-10-27. 우주 여행은 하나의 **태양계 탈출** 코스를 제공한다.

지구 → 달 → 화성 → 목성 → 토성 → 천왕성 → 해왕성 → 명왕성 → 태양계 밖.

지구에서 바깥 방향으로 이어지는 실제 천체들을 경유한 뒤 행성이 없는 별 배경으로 진입한다.
명왕성은 태양계의 물리적 경계가 아닌 중간 근접 통과 지점이다. 마지막 구간은 그 너머로 떠나는 연출이다.
실제 항법 계획·행성 정렬·중력 보조 궤적을 계산하지 않으며 거리·크기·시간은 집중 세션에 맞춘다.

천체에 대한 기존 참고 자료:
- [NASA · Solar system planets](https://science.nasa.gov/solar-system/planets/)
- [NASA · Pluto](https://science.nasa.gov/dwarf-planets/pluto/)

기존 11개 코스는 선택 목록에서 제거하고 ID를 단일 코스의 별칭으로 유지한다.
저장된 우주선 여행은 같은 집중 시계와 방향으로 새 코스에서 복원한다. 미처리 완료 알림도 새 코스로 해석한다.
외계행성 등 기존 그림 구현·보관된 관측 자료는 남아 있지만 현재 코스에는 포함하지 않는다.

## Canvas 풍경과 행성

기차 풍경처럼 Android Canvas의 경로·도형·그라디언트를 겹쳐 원본 일러스트를 그린다.
사진·다운로드 지도·미리 생성한 WebP는 사용하지 않으며 해당 파일과 생성 스크립트도 제거했다.
`EarthContours`의 수작업 경위도 윤곽을 직교 구면 투영해 대륙을 그리고, `PlanetPainter`에서
지형·구름·행성별 특징을 추가한다. 경계에서 뒷면을 잘라 대륙이 구면의 가장자리를 따라 휘도록 한다.

- 지구: 유라시아·아프리카·아메리카 등의 해안선, 지중해·카스피해, 사하라·아라비아,
  산맥·극지 얼음·끊어진 구름대와 나선형 기상계를 겹친다. 구름 배치와 조명은 연출이다.
- 목성: 위도에 따라 휘는 띠, 가는 난류 경계, 남반구의 대적점과 작은 소용돌이,
  극 방향 편평도를 그린다. 대적점의 현재 관측 크기·색·위치를 실시간으로 재현하지 않는다.
- 달·수성: 명암이 있는 크레이터·방사형 분출 흔적. 달의 어두운 바다 분포를 별도로 그린다.
- 금성: 지표를 노출하지 않고 두꺼운 구름의 곡선 무늬를 그린다.
- 화성: 적갈색 토양·어두운 영역·극관, 타르시스 화산과 매리너 계곡을 요약한다.
- 토성: 은은한 띠·극지 소용돌이와 북극 육각형, 카시니 간극을 가진 고리를 그린다.
- 천왕성: 옅은 청록색 구름층과 옆으로 기운 고리. 해왕성: 차분한 청색 띠와 가는 흰 구름,
  일시적인 폭풍의 해석도. 명왕성: 서로 다른 두 엽의 하트 지형과 밝은 평원 세포 무늬.
- 외계행성: 관측으로 확정하지 못한 지표는 코스 설명처럼 해석도임을 유지한다.

행성은 최초 사용 때 Canvas로 1024px 메모리 비트맵에 그려 동시 최대 3개(약 12MiB)만 캐시한다.
프레임마다 수백 개의 지형 경로를 다시 계산하지 않으며, 화면 종료 시 캐시를 해제한다.
지상은 사진 대신 바다·산 능선·해안·습지·들판·수목을 Canvas 레이어로 그려 아래로 이동시킨다.

출발은 해안 지상 → 수직 상승·구름 통과 → 푸른 대기권 가장자리 → 궤도 회전 → 우주 항해다.
일반 세션에서는 3초 동안 상승한 뒤 1초 동안 항해 방향으로 회전하고, 12초에 달을 근접 통과한다.
짧은 테스트 세션은 이 시각을 비례해서 줄인다. 나머지 집중 시간은 후속 경유지와 최종 탈출 구간에 배분한다.
각 행성의 접근·이탈은 최대 8초로 압축하고 그 사이를 순항해 행성이 오랫동안 창에 멈춰 있지 않게 한다.
별은 세션의 경과 초에 따라 일정한 속도로 흐르며 짧은 궤적과 깊이별 시차로 속도감을 표현한다.
세션 진행률에만 비례하던 별 이동을 제거해 25·50·90분에서도 같은 순항 속도감을 유지한다.

화면·남은 시간·방문 기록·왕복·위치 탐색·기동음은 같은 비균등 시간표를 사용한다.
위치 탐색은 가속된 카메라 경로의 역함수를 사용한다. 일시정지·탐색·재시작에도 같은
세션 진행률에서 같은 장면을 표시한다. 별 배경·조명·각지름·창틀은 연출이며 모든 풍경은 직접 그린 그림이다.

## 우주선 사운드

`SpaceAudio`가 `VoyageAudio`를 구현하며 우주선 모듈이 음색과 상태를 소유한다. 연속 PCM 스트림으로
이륙 엔진의 저음·중음 배음·기체 통과 공기음, 궤도 이후 공조/기계음, 근접 통과 시 자세 제어 추진기음을 합성한다.
외부 진공에서 소리가 전달된다는 표현이 아니라 선내에서 들리는 연출이다. 휴대폰에서도 들리도록
376/392/588Hz 등의 성분을 포함하며, 55Hz 단일 저음 위주였던 공통 루프는 우주선에서 사용하지 않는다.
기차·배·비행기 사운드는 기존 구현을 유지한다. 일시정지 때 엔진과 기동음은 줄고 조용한 선내음만 남는다.
기존 소리 켜짐/크기 설정을 따르며 화면이 가려지거나 꺼지면 정지하고, 화면 종료 시 AudioTrack을 해제한다.
