# 노선 위치 안내

8개 코스 모두 `Course.guide`에 정차역과 통과 지역을 둔다. 지명은 한국어·영어 리소스로 제공한다.
실제 노선의 대표 지점과 경유 순서를 바탕으로 한 가상 열차 위치이며, 사용자 기기의 GPS 위치는 읽지 않는다.

`RouteGuide.kmAt`은 풍경이 쓰는 `CoursePlan.distanceAt(t) / segDist`를 각 정차역 사이의
철도 거리 비율로 옮긴다. 정차역 사이를 화면에서 같은 길이로 그리는 기존 계획은 유지하며,
그 안의 경유 지역은 균등 간격으로 배치하지 않는다. 돌아오는 길은 같은 거리 축을 뒤집는다.
일시정지·복원도 세션의 동일한 경과 시간을 사용한다.

대표 지점 반경 최대 6 km 안에서만 안내한다. 가까운 지점끼리는 간격의 40%로 반경을 줄여
안내가 겹치지 않게 한다. 정차 중에는 정차 문구가 우선하며, 역 주변에서는 출발·도착 접근 문구를 쓴다.
기본 화면에는 8초간 작게 표시하고 0.7초 동안 나타나고 사라진다. 조작 오버레이와 반접기 정보판에도
현재 위치를 표시한다. 일시정지 중에는 통과 문구를 숨긴다.

## 자료와 거리 축

경유 순서는 운영사·철도 사업 자료로 확인했다. km는 도시 이름으로 단순화한 역의 영업거리 또는
대표 지점의 대략적인 거리이며, 측량 좌표·행정구역 경계·실시간 운행 정보는 아니다.
서로 다른 노선의 영업거리 기준점은 코스 출발점으로 맞췄다. 역 이전이나 노선 변경 시 다시 확인한다.

새 코스는 `guide`가 필수다. 코스 초기화 시 안내 정차역과 실제 코스의 정차역 이름·순서를 대조한다.
`RouteGuideTest`는 8개 코스의 25·50·90분 여행을 양방향으로 훑어 모든 통과 지역의 순서와
노출 여부, 정차·거리 비율·경과 시간 재현을 확인한다.
